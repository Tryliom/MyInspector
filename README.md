# My Inspector
My Inspector is a Unity Editor extension that provides a customizable and user-friendly interface for inspecting and modifying your game objects and components. It enhances the default Unity Inspector by allowing you to create custom inspectors, organize properties into sections, and add additional functionality to improve your workflow.

Based on [NaughtyAttributes](https://github.com/dbrizov/NaughtyAttributes), I was obliged to create this package because Odin is not compatible with modding (their license cost A LOT), so it's very inspired by Odin, but turn faster than it.
It doesn't have all the features of Odin, but it has a lot of them, and it's free and open-source. You can use it in your projects without any restrictions and fork it to add your own features.
